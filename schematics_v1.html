Visual guide · one chassis

Schematics for the box

Textbook topologies, drawn the way Arrow draws them. Every wire ends on a pin. IEC boxes. Feedback over the top.

How to read one of these

  1. Input hits a box, then the − (or +) stub. It never dives into the triangle.
  2. Feedback leaves the output, goes over the top, and T-joins the input wire before the pin.
  3. + to ground is a short stub and a down-arrow, same as the Arrow page.

First-order computer

§1.2.3 + §2.4.1 · uses Figure 1.2a and the integrator

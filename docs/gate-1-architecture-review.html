04 · Honest limits

What Gate 1 does not claim

  • The probe is an inverter, not the Figure 9.1 transistor amplifier.
  • No installed simulator has parsed or simulated a generated deck; ngspice installation requires a separate in-scope implementation decision.
  • The prototype SPICE check still uses projection metadata as an aid. Week 9 must parse actual element terminals and subcircuit pin order independently.
  • Week 9 Transcription B, raster-junction adjudication, model provenance, fixture resistance, parasitics, and provisional compensation remain required before encoding.
  • Publication layout, hierarchy, collision handling, and print fidelity remain Gate 2 proof obligations.
Gate boundary

Approving Gate 1 authorizes the Week 9 vertical proof only. It does not authorize chronological batch production or insertion into capstone.html.

How other projects make schematics

We have been drawing pictures of circuits. Projects that ship correct schematics declare nets, then render pins.

Verdict

The gap is the representation, not the coordinates.

Hand SVG, book crops, and schemdraw are one family: a wire is a line. A pin is a visual target. A junction is a dot you remember to add.

The connection checker is the same idea — geometry after the fact, not electrical rules. That is why week 8–10 and the plant never finish.

Most likely to work here: lcapy netlists → CircuiTikZ. Second: draw once in KiCad and export. Stop patching schemdraw.

Ranked paths

Ranked for this project: 20 analog teaching figures that must look like Roberge, stay incremental week to week, and stop having wires through triangles.

1. lcapy netlist → CircuiTikZ SVG

pick first

Likely Needs LaTeX

You write a SPICE-like netlist. Same node name = same net. Direction is a constraint (right, down), not a pen move. Junctions are automatic. Wires are W n1 n2. Op-amps, transistors, and feedback are first-class.

This is the academic analog path. Hayes 2022: textbook-quality schematics from netlists. Official docs include op-amp and transistor examples.

Fit: analog + book-like layout + Python generator. Cost: install texlive + circuitikz (not on this machine yet). Coverage: every electrical circuit in schematics.html; not the chassis maps. See inventory.

2. Draw in KiCad, export SVG

pick if no LaTeX

Likely Manual

This is how Arrow-quality diagrams get made. Symbols have pins. Wires are nets. ERC exists. Export PDF/SVG. Twenty figures is a weekend of drawing, not months of turtle debug.

Incremental weeks = “save as week N+1” or a hierarchical sheet. Same electrical honesty as lcapy. Worse to version in git than a netlist.

Same family: Xschem, LTspice, QUCS. Use any real EDA editor.

3. Stop generating. Use the book crops

honest fallback

Works now Not generated

We already have figures/book/*.png. They are electrically correct because they came from the book. If the goal is “show the student the circuit,” this is already done.

Give up generated SVGs until a netlist renderer exists. Keep crops as the visual spec either way.

4. SKiDL generate_schematic()

ERC only

Correct nets Ugly layout

Python Net + pins. ERC. Auto place/route into KiCad. Connectivity is the source of truth. Auto-layout looks like a compiler dump, not Fig 5.3.

Use later if you want a second check: “is this electrically the book circuit?” Do not use as the teaching-figure renderer.

5. tscircuit / atopile / netlistsvg

wrong product

Skip for figures

tscircuit and atopile are PCB-as-code. Schematic is a view of a board. netlistsvg + elkjs auto-routes from a Yosys JSON graph. Digital-first. Analog skin exists. Layout is Sugiyama, not left-to-right analog computer.

They prove the method (nets first). They will not look like Roberge.

6. Keep patching schemdraw / hand SVG / more checkers

will not close

Do not do this

Same class of tool as the last three attempts. Pin anchors help. They do not create a net. Geometric checkers treat the symptom. Week 8–10 already hit the 3-attempt stop.

Why we stall

_gen_engine.py is turtle graphics. A typical move:

d += elm.Line().right().length(0.4)
op = elm.Opamp().anchor("in1")
d += elm.Line().at(op.out).right()

Feedback is “go up, go across, hope you miss the triangle.” Junction dots are optional decorations. Incremental weeks copy the drawing script and add more pen moves.

The checker looks for segments inside the op-amp triangle and unmarked T-joins. That is a picture linter, not ERC.

Four families other projects use

Family Source of truth Examples Transfers here?
Drawing language Coordinates / turtle Hand SVG, schemdraw, raw CircuiTikZ No. This is what we have.
Netlist + placement hints Named nodes. Hints only rotate/stretch. lcapy → CircuiTikZ Yes. Analog + book-like control.
Code-as-circuit Nets and pins. Schematic is a view. SKiDL, atopile, tscircuit Nets yes. Auto-layout no.
Graph layout Netlist graph + elkjs netlistsvg, d3-hwschematic Nets yes. Looks digital.
Real EDA, export figure Symbol + pin + wire graph KiCad, Xschem, LTspice Yes if we accept manual draw.

What actually transfers

  • Named nodes / nets as the file we edit.
  • A renderer that attaches to pins. You cannot miss the inverting input.
  • Automatic T-join dots.
  • Placement hints, not full auto-layout — figures must still look like the book.
  • Book crops as the visual spec. A drawing is done when it matches the book and the netlist.

Same inverter, two models

What we write today (picture)

d += elm.Resistor().right()
d += elm.Line().right().length(0.4)
d += elm.Opamp().anchor("in1")

What a working project writes (net)

R1 vin vm; right
E1 vo 0 opamp vm 0; right
Rf vo vm; left

vm is one node. R1, the inverting pin, and Rf must meet there. That is the whole method change.

Can we write an lcapy netlist for each circuit in schematics.html?

Yes — for every electrical circuit. Not for the week chassis maps. Those are board overviews, not one netlist.

lcapy already has the parts we need: op-amp (E … opamp), R/C, sources, wires, ground, diodes, BJTs, and switches (SW no/nc/spdt). A pot is either a pot symbol or two resistors plus a tap node.

Do not write as one netlist

The 13 “the box so far” chassis drawings in schematics.html. They mix:

  • several unconnected modules
  • empty sockets
  • a box labeled “INT1 Fig 9.1” instead of the transistors

A netlist of that is either a pile of islands or a fake. Keep those as a separate board map, or drop them once the module netlists exist.

Honest limit

The connectivity can be written for every row above. The discrete channel (weeks 8–10) may still look crowded after CircuiTikZ places it. The netlist will still be electrically the book circuit. If that drawing is ugly, that one figure goes to KiCad. We do not go back to schemdraw.

When the ranking is wrong

  • You only need a screenshot pack and will accept book crops — then stop generating. Path 3 wins.
  • You refuse LaTeX — then KiCad export, not another drawing library.
  • You want a PCB from the same source — then SKiDL or atopile, and live with auto-layout.
  • A one-circuit lcapy spike looks worse than the book and cannot be hinted into shape — then drop to path 2.

First useful spike
